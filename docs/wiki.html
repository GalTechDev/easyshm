The EasySHM Class

The main entry point for EasySHM.

from easyshm import EasySHM

# Create segment (1MB)
shm = EasySHM("shared_bus", size=1024*1024)

# Write raw bytes
shm.write(b"Hello RAM!", offset=0)

# Read raw bytes
data = shm.read(size=10, offset=0)

NumPy Integration

EasySHM supports zero-copy views for NumPy arrays.

arr = shm.as_ndarray(shape=(1920, 1080, 3), dtype='uint8')
arr[:] = 255 # Instantly white screen for all processes!

Process Signaling

Instead of polling, wait for a signal.

if shm.wait_update(timeout=5.0):
    print("Data updated!")

Advanced Views

Map complex Python objects directly over shared memory.

Supported Types

  • numpy: Multi-dimensional arrays (Zero-Copy).
  • struct: C-style ctypes.Structure.
  • torch: CPU Tensors for AI workloads.

Custom C-Structure Example

class Player(ctypes.Structure):
    _fields_ = [("x", ctypes.c_int), ("y", ctypes.c_int)]

p = shm.as_view("struct", type=Player)
p.x = 100

Windows Implementation

On Windows, EasySHM uses Named Events in the 'Local\\' session namespace.

Signals are broadcast using PulseEvent.

Linux Implementation

EasySHM uses /dev/shm and POSIX Semaphores on Linux.

You can manually inspect shared segments in /dev/shm.
